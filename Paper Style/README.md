 White Paper, Takeda Project

This folder includes the white paper prepared for the Takeda team project.  
It summarizes the full work in a paper-style format, similar to a research report.  
The document starts with a short executive summary, followed by sections that introduce the problem, describe the data, and present key visualizations.  
It then explains the modeling process, main results, and both useful and less successful directions that shaped the project.  
A short pseudocode section outlines the core methods used, and the paper ends with a brief conclusion, ideas for future work, and references.
